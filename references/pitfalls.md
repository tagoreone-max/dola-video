# dola 实测坑位记录

（实测记录：probe.py 探测 dola.com/chat；随后完整跑通「产品口播」视频生成 → 下载 → 去水印。
日期见仓库提交历史。）

## 0. 肖像保护：真人脸参考图被拦（重要实测）

**Seedance 2.0 拒绝用真人脸参考图生成视频**，报错：
「出于肖像保护考虑，未认证人脸暂不支持用 Dreamina Seedance 2.0 生成视频。
你可以尝试换其它参考图或文生视频。」

**对策（已验证可行）**：
- 不传含清晰人脸的参考图（正脸/全身/侧面都算）
- 上传**产品白底图**（无人物），人物用**文字反推描述**写进提示词——
  实测「年轻时尚女主播 + 产品图」组合可正常生成，人物由模型自行合成
- 需要真人形象时：走支持人脸认证的平台，或先完成认证

## 0.5 发送：无发送按钮，Enter 提交（重要实测）

dola 输入区**没有可点击的发送按钮**（豆包有）。填完提示词后
**直接在 ProseMirror 里按 Enter 即提交**。`generate.py` 会先尝试找发送按钮，
找不到则回退 `keyboard.press("Enter")`——这段 fallback 不要删。

## 0.6 下载：页面 fetch 被拦截，须直链回退

dola 视频 CDN 直链可直连下载（回退分支成功）：
- 页面内 fetch（带 cookie）被平台隐私框架拦截（Failed to fetch）
- `wait_download.py` 的直链回退逻辑有效
- 实测出片 10.08s / 720x1280 / 带 aac 音轨（口播+字幕+音频一次生成）

## 0.7 水印落在右下角，但坐标必须每次实测

产品口播成片（720x1280）的水印落在**右下角一小块**，静态烧录。
具体 `x/y/w/h` 会随画幅、平台改版浮动，**本仓库刻意不记录现成参数**——
每次出片先跑 `watermark.py locate` 读字符画边界，再按读到的值四边各留 20-40px 传给 `remove`。

## 1. 界面是中文，不是英文（重要纠正）

初版判断误以为 dola 是英文界面。实测：**dola 界面与国内豆包几乎同构**——
ProseMirror 输入框、底部「视频生成」入口、中文参数文案。豆包 skill 的
选择器逻辑大部分直接适用。但**账号、额度、水印独立**，不要混用。

> 因此所有状态判定正则必须**中英并存**（`生成中|排队|创作中` 与 `generating|queued` 一起写），
> 只写英文会在中文界面上永远判不出来。

## 2. 上传控件常驻在视频生成模式下（补充实测）

视频生成模式下页面有常驻 `input[type=file]`（accept=.jpg,.png,.jpeg,.webp），
`upload_images.py` 直注可成功，多图会**追加**到输入区（实测挂 5 张 OK）。
「新对话」按钮在左侧栏，点后可清空输入区。

## 3. 时长档位可能比豆包多 5s

豆包档位 4s/10s/15s；dola 探测正则里加了 5s 兜底。首次配置时用
`generate.py --list` 看实际档位，不要照搬豆包的三个档。

## 4. 水印右下角固定，但仍要人工判读

- 位置固定、静态烧录，**截单帧即可定位**，无需复杂多帧检测
- 国内豆包踩过的坑依然适用：
  - 自动检测算法（差分/方差/梯度）在静止背景 + 半透明水印下**全部失灵**
  - 必须用字符画人工判读，且**逐行数行号**（曾因 Y 坐标偏 20px 导致残留返工）
  - delogo 区域不贴画面边缘（右/下留 ≥4px）
  - 从原片处理，不二次涂抹

## 5. 双重代理问题

- 访问 dola.com 需走系统代理——浏览器自动处理
- Python 连 CDP（127.0.0.1:9222）必须绕代理——`browser_common.py` 已内置
  （import 时清空 HTTP(S)_PROXY 并用 ProxyHandler({})）。**勿删这段逻辑**，
  否则 CDP 请求返回 502。

## 6. 登录态独立且敏感

dola 与国内豆包不同号，登录态互相独立。掉登录时页面出现登录按钮，
让用户在受控窗口重登一次即可，之后保存在 `DOLA_PROFILE_DIR`
（默认 `~/.dola-video/browser-profile`）。

> 该目录含完整登录凭据：**不要提交进仓库、不要打包分享**。`.gitignore` 已排除。

## 7. 免费额度有限

dola 走免费额度，每日紧张。策略：
- 提交前先看页面剩余额度，告知用户
- 额度不足时换其它已开通额度的平台，或次日再跑
