# 电商视频分镜与提示词模板

> 本模板为电商视频通用提示词写法，适用于 dola / 豆包 / liblib / runninghub 等主流视频模型。
> dola 特有注意：模型同 Seedance 引擎，规则与豆包一致；台词/字幕保留中文原文，
> 场景描述可英文；多段时固定锚点逐字复制；水印右下角固定（见 SKILL.md 阶段四）。


## 15-30 秒标准分镜结构

| 段 | 时长 | 任务 | 要点 |
|---|---|---|---|
| 1 开场 | 3-5s | 钩子 | 京东：产品亮相；抖音：痛点/反差/悬念 |
| 2 产品展示 | 5-8s | 主体呈现 | 360° 或推近，突出外观质感 |
| 3 卖点细节 | 5-8s | 核心卖点 | 每个卖点一个镜头动作 |
| 4 模特/场景 | 5-8s | 使用体验 | 手持、上身、使用场景 |
| 5 收尾 | 3-5s | 转化引导 | 品牌+型号；抖音加引导话术 |

总时长 15s 时压缩为 3 段（开场 4s + 卖点 6s + 收尾 5s）。

## 提示词通用骨架

```
[主体描述] + [镜头运动] + [动作/表情] + [场景与光线]
+ [一致性锚点] + [文字层] + [音频层] + [画质约束]
```

- **一致性锚点（必写）**：`保持人物五官、发型、服装与参考图完全一致` / `保持产品外观、颜色、logo 与参考图一致`
- **文字层（需字幕/Logo 时写）**：内容 + 位置 + 样式 + 避让要求
- **音频层（需口播时写）**：台词原文（用「」括起来）+ 音色要求
- **画质约束（必写）**：`画面稳定、无卡顿、无变形、光影自然`
- **负面约束**：`不要多余手指，文字不得覆盖产品主体、不得压住产品轮廓`

> 注意：**不要**写"不要出现文字/字幕"——平台模型能生成文字，写了反而把需要的字幕屏蔽掉。
> 需要字幕就明确描述要什么字、放在哪。

## 多段一致性锚点（硬性要求）

**两段及以上需拼接时，下列锚点必须在每一段提示词中逐字复制，一字不改。**
模型没有跨段记忆，措辞一变，风格/人物/产品就会漂移。

### 1. 固定人物锚点（有模特时）

```
人物为同一位{性别}，{发型描述}，{服装描述}，五官、脸型、肤色、身材与参考图完全一致，
全程保持同一人物形象，不得更换人物
```

### 2. 固定产品锚点

```
产品为{品牌}{型号}，{颜色}，{材质}，外观、比例、颜色、logo 位置与参考图完全一致，
全程同一件产品，不得变形、不得更换款式
```

### 3. 固定风格锚点

```
{风格描述，如：明亮干净的商业摄影风格 / 暖色调生活化纪实风格}，
{光线描述，如：柔和均匀的棚拍布光 / 傍晚暖光}，
{色调描述，如：白净高调 / 低饱和莫兰迪色}，
{镜头语言，如：固定机位缓慢推近 / 手持轻微晃动}，
全片视觉风格统一
```

### 4. 固定场景锚点

```
背景为{场景描述，如：纯白无影背景 / 简约北欧风客厅}，
全程同一场景，不得更换背景
```

### 使用方式

1. 第 1 段生成前，先把这四个锚点**拼成一段固定文本**
2. 之后每一段提示词 = `固定锚点文本` + `本段镜头任务`，锚点部分**原样复制**
3. 所有段落**在同一会话内**连续提交（上下文连贯，一致性更好）
4. 进阶：把上一段的**尾帧截图作为下一段的参考图**上传，衔接最稳

## 音频层写法（口播 · 旁白 · 画外音 · BGM）

所有音频都在生成阶段由视频模型一次生成。每段提示词的音频层包含以下四块：

### 1. 人物口播（画面内人物说话）

```
人物正面朝向镜头，自然开口说话，台词：「{台词}」，
唇形与台词精确同步，音色为{温柔女声/清亮男声}，语速自然
```

### 2. 旁白 / 画外音（画外解说）

```
画外音旁白：「{解说词}」，{沉稳男声/温柔女声}，语速适中，
情感饱满，与画面内容同步
```

- 旁白解说词与人物台词分开写，不要混在同一句
- 一段里口播与旁白通常二选一，避免两条人声同时挤在一起

### 3. 背景音乐（固定 BGM 的关键）

**多段拼接时，这段 BGM 描述必须逐字复制、一字不改。**

```
背景音乐为{轻快明亮的电子流行乐}，{钢琴+电子鼓点}为主，
BPM 约 {120}，{活泼向上/温暖治愈}的情绪，音量适中，
不影响人声清晰度，全片统一
```

- 写具体到四项：**风格 / 乐器 / BPM / 情绪**
- 与一致性锚点同理：写好后全程不改，逐字复制到每一段
- 生成后逐段试听，某段 BGM 明显跑偏就只重生成该段

### 4. 口播与旁白的关系

- 纯口播：只写人物台词，BGM 垫底
- 纯旁白：只写画外音，人物只做展示不说话
- 两者都要：明确写"人物说话时旁白暂停"，否则两条人声会打架

## 字幕与旁白文字写法

**必须同时写"文字放哪"和"产品放哪"**，模型才会自动避让。

```
画面底部约 80% 高度处居中显示白色描边字幕文字：「{字幕内容}」，
字号适中清晰易读，产品位于画面中部约 40% 高度处，
文字与产品保持距离，不得遮挡产品主体与轮廓
```

旁白/口播：

```
模特正对镜头，自然开口说道：「{台词}」，唇形与台词精确同步，
同时画面底部显示对应字幕：「{台词}」，字幕不遮挡产品
```

Logo：

```
画面{右上角/底部中央}显示品牌 Logo「{品牌名}」，{颜色}字形，清晰不模糊，
位置固定不移动，不遮挡产品主体
```

要点：

- 字幕文字用「」括起来，与镜头描述区分开
- 一段只出 1-2 行字，字太多会糊
- 品牌名、型号必须核对，写错等于废片
- 生成后逐段检查：文字是否压住产品、字形是否清晰

## 京东风格模板

```
{产品名} 置于纯白背景中央，镜头缓慢环绕一周，柔和均匀的棚拍布光，
清晰呈现产品外观与材质细节，{卖点1}，{卖点2}，
保持产品颜色、形状、logo 与参考图完全一致，
固定机位，画面稳定无抖动，商业摄影质感，8K 细节
```

口播版追加：
```
模特正对镜头，面带自然微笑，开口说道：「{台词}」，
唇形与台词精确同步，表情亲切，头部轻微自然活动，
保持人物形象、服装与背景和参考图完全一致
```

## 抖音风格模板

```
开场特写：{痛点或反差画面}，强冲击力，镜头快速推近，
随后切换到 {产品} 亮相，{使用场景} 中模特真实使用，表情惊喜自然，
节奏明快，手持微晃动感，暖色调生活化光线，
保持人物与产品与参考图完全一致，画面清晰无变形
```

## 台词撰写要点

- 单段不超过 2 句，总字数控制在 15 字内最稳（唇形同步率最高）
- 必须包含**品牌 + 型号**（用户提供的，不可臆造）
- 避免生僻字与连读，唇形容易崩
- 例：`大家好，我是XX品牌A1，很高兴跟大家见面`

## 提交流程建议

1. **先确定四段固定锚点文本**（人物/产品/风格/场景），写下来全程不改
2. **只生成第 1 段**，给用户确认风格、人物与产品还原度、字幕位置是否遮挡
3. 确认后批量生成剩余段落——**每段提示词 = 固定锚点（原样复制）+ 本段镜头任务**，同一会话内连续提交
4. 每段生成后**逐段核验**：人物是否变脸、产品是否变形、风格是否漂移、字幕是否压住产品
5. 全部下载后拼接 → 去水印 → 铺固定 BGM → 交付

> 去水印要在**拼接之后**对整片做一次，还是**每段单独**做？
> 推荐：每段单独去水印再拼接（各段水印位置一致，参数可复用），
> 也可先拼接再对整片去一次水印，效率更高。两者效果相同。

## 多段一致性检查表

拼接前逐段对照，任何一项不符就重生成该段：

| 检查项 | 不合格表现 |
|---|---|
| 人物 | 脸型/发型/服装变了，或换了人 |
| 产品 | 颜色/形状/logo 位置变了，比例失真 |
| 风格 | 光线、色调、饱和度明显不同 |
| 背景 | 场景切换了（非有意设计） |
| 字幕 | 位置跳动、字形不一致、压住产品 |
| 音频 | 各段人声音色不一致、BGM 旋律不同 |
