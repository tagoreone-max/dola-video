# dola（豆包国际版）参数与规格

> 实测校准：**dola 为中文界面，与国内豆包高度同构**
> （ProseMirror 输入框、底部「视频生成」入口、中文参数文案）。

## 基本信息

| 项 | 内容 |
|---|---|
| 产品 | dola.com，豆包国际版（前身 Cici），字节海外 |
| 模型 | Seedance 系（与国内豆包同引擎） |
| 界面 | **中文**（实测；与豆包同构，非英文） |
| 网络 | 需海外网络出口（系统代理即可）；CDP 本地连接须绕代理（browser_common.py 已处理） |
| 登录 | 独立海外账号，支持 Google / FB / 海外手机号；与国内豆包账号**完全独立** |
| 额度 | 免费额度，每日积分/次数有限，以页面显示为准 |
| 水印 | 右下角固定位置、静态烧录（详见下节） |

## 实测界面结构（probe.py）

- 输入框：`div.tiptap.ProseMirror`（同豆包）
- 底部工具栏：＋ / 快速 / **视频生成** / 图像生成 / 帮我写作 / 翻译 / 拍题答疑 等
- 点「视频生成」后出现参数按钮（比例 / 时长 / 模型，中文文案）
- 视频生成模式下有常驻 `input[type=file]`（accept 含 .jpg/.png/.jpeg/.webp）

## 免费额度

海外版免费额度紧张（每日积分/次数有限，具体以页面显示为准）。
**每次使用前先看页面剩余额度**，评估当天能跑几条并告知用户：
- 测试/样片 → 4s 短片最省
- 批量生产 → 额度不足时换其它已开通额度的平台，或次日再跑

## 参数

| 参数 | 可选值 |
|---|---|
| 比例 | 自动 / 9:16 / 16:9 / 3:4 / 4:3 / 1:1 / 21:9 |
| 时长 | 4s / 5s / 10s / 15s（档位以 `generate.py --list` 实测为准，可能比国内豆包多 5s） |
| 模型 | Seedance 系各档 |

## 水印

- **位置固定：右下角**，静态烧录
- **截单帧即可定位**——不需要复杂的多帧检测；直接单帧字符画定位即可
- 自动检测算法（差分/方差/梯度）在静止背景 + 半透明水印场景**全部失灵**，与豆包同样要绕
- 去除用 `scripts/watermark.py locate/remove`（通用 delogo 工具）
- delogo 区域不贴画面边缘（右/下留 ≥4px，脚本已自动内缩）
- 坐标随画幅与平台改版浮动，**每次出片先 `locate` 复核，不要照搬历史数字**

## 提示词语言

Seedance 海外版训练分布英文占比高，**英文提示词通常更稳**：
- 镜头/场景/风格描述 → 英文
- 口播台词/字幕内容 → 保留中文原文（生成的语音和文字跟着台词语言走）
- 固定锚点、字幕避让、BGM 描述等写法与豆包基本一致，见 prompt-templates.md

## 多段策略

单段上限 15s，30s = 2×15s；同一会话连续提交、固定锚点逐字复制、
尾帧接首帧；拼接用 `scripts/concat.py`；**逐段去水印**（位置固定参数可复用）或拼完去一次。
